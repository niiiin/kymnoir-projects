# Pumpkin Music & Mindfulness

Public mood-music and mindfulness collection at /pumpkin/music/.

- All content is intended to be original recordings created or controlled by KYM CORE / Pumpkin.
- The current \`catalog.json\` is a **production wishlist**, not an audio library. Every \`src\` is \`null\`, and the public page clearly says "Coming soon."
- The HTML includes a working native HTML5 audio player that becomes available when the original audio file for a track is placed in \`/var/www/html/pumpkin/music/audio/\` and the corresponding \`src\` is updated in \`catalog.json\` (e.g., \`audio/first-light.mp3\`).
- Suggested formats: .mp3 for broad mobile support; optional .m4a. Use filenames with only letters, numbers, dash, underscore and dot.
- Avoid embedding files in the GitHub repository until we decide our audio storage and licensing strategy. Never add third-party commercial recordings without the necessary rights.
- No autoplay; listening begins only after the user taps play.
- Future features: background play/mobile-app audio session, playlists, downloadable premium sessions (only with appropriate access controls), optional voice-guided mindfulness and adaptive recommendations based on stated mood (not inferred medical conditions).
- No paid music-generation account, external account, or live server deployment is required to view the page.

The section is a public demo for now. Keep private drafts and unreleased masters off this public site.
